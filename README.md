# GPT-3 Landing Page

A single-page marketing site on an AI product theme — a gradient-heavy layout
built in plain React and hand-written CSS, with no UI framework.

[Live demo](https://personalblog-gpt3.netlify.app)

## Sections

Header · What is GPT-3 · Possibilities · Features · Blog · Call to action ·
Brand strip · Footer

Structured as `components/` for small reusable pieces and `containers/` for
full page sections.

## Stack

React · CSS (custom properties, flexbox, media queries) · Create React App

## Running locally

```bash
npm install
npm start
```
